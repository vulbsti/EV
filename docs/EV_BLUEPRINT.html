§ 0808

Six ways this becomes a dashboard that lies

SEV H/M/L ↔ MITIGATIONS
R1 · scrapingHIGH

Terminal text misread as state

False progress, missed approvals, stalled agents shown working.

MitigationProtocols first; confidence badge on every card; truth inspector to raw facts.
R2 · voiceHIGH

Misheard destructive verb

"Don't delete" → delete; wrong pane, wrong branch, wrong minute.

MitigationFrozen context + risk gate + non-voice confirmation; corpus-tested WER/intent.
R3 · collisionHIGH

Two agents, one tree

Mixed diffs, lost attribution, unverifiable receipts.

MitigationWorktree per run, file reservations, conflict warnings, independent verifier.
R4 · secretsMED

Logs leak into ledger/model/UI

Tokens in terminal tails, patches, notifications, prompts.

MitigationBounded capture, regex redaction, retention caps; never raw fleet by default.
R5 · driftMED

Orchestrator context rots

Decisions on stale fleet; completion declared on vibes.

MitigationDB is truth; fresh evidence per turn; verification evidence required.
R6 · autonomyLOW·EARNED

Ambient overreach

Silent actions, interrupt spam, trust crater.

MitigationPTT default, interrupt budget 2–4/day, activity log one tap away; Level 4 earned.

Eight decisions that cascade

CORE ARTIFACT ↔ GAIN / TRADE
6.1axis · universal vs owned

tmux-direct baseline, managers as adapters

Stable IDs + concurrent capture-pane + 600 ms cache see all 16 panes including unmanaged ones.

Gained
Whole fleet day one; no namespace lock-in.
Traded
Polling heuristics; VT fidelity deferred.
6.2axis · prompt vs gateway

Authority boundary in code

Companion allows 5 read tools; 6 mutating names delegate. Envelopes carry utterance-ID idempotency.

Gained
Zero mutation leaks even on model misbehavior.
Traded
Queue-only v1; execution arrives later.
6.3axis · demo vs measurement

Lab before product

11 experiments with JSONL evidence; 7 build gates; no transport chosen on docs alone.

Gained
Real P50/P95, WER 8.33% sample, cost facts.
Traded
Slower visible UI; open transport choice.
6.4axis · same thread vs second

Isolated explainer thread + window

Fresh evidence per ask, read-only Codex thread, public-only browser projection, JSONL sessions.

Gained
Questions never contaminate execution.
Traded
2 turns at 36; no streaming; global profile.
6.5axis · instruct vs compile

Deterministic 650·6·5 budgets

Deep investigation, then local parse/link/bound; invalid links dropped, fallback explicit.

Gained
UI unbreakable by verbosity; selectable depth.
Traded
A normalizer to own; schema drift handled.
6.6axis · run-all vs honest-no

Narrow adapters + missing-adapter

Two capabilities, exact authority equality, 3-run suites, failed assertions → proposals.

Gained
Every run real; 10/10 means receipts.
Traded
Most domains unscored until adapters land.
6.7axis · hard-coded vs manifest

Generic probe core (worktree)

Schema-v2 manifests, disposable snapshots, prlimit runner, feed/RPC bridge, confirmed calibration.

Gained
Harness-neutral probes; user-driven verdicts.
Traded
Two labs carried; merge pending.
6.8axis · blocks vs map

Hover-to-explain as primary UI

Fleet map + wall + task graph over one dataset; hover expands to rationale, evidence, runnable edges.

Gained
Cognitive load collapses to one sentence + drill-down.
Traded
Every hover must carry evidence status or it lies.
