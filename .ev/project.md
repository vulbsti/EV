# EV interactive understanding environment

EV is a local-first mission control for terminal agents. The current objective is to let a user understand what an agent built without reading its entire implementation or contaminating the executor's context.

For the `interactive-explainer` branch, success means converting evidence into a mechanistic capability model and letting the user execute safe feature experiments, vary edge cases, observe real pipeline behavior, measure limits and costs, compare behavior, and retain reproducible receipts.

The explainer remains read-only. Executable learning is delegated to bounded, explicitly selected capability adapters.
